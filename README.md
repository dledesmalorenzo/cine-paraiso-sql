# Cine Paraíso · laboratorio de SQL

Juego para practicar SQL en el navegador. Usa SQLite (sql.js) y los ejercicios se corrigen solos.

## Qué incluye

- 7 bloques de ejercicios: SELECT, WHERE, AND/OR/LIKE, ORDER BY, COUNT/SUM/AVG, GROUP BY/HAVING y NULL/CASE.
- Una misión final, «Las entradas fantasma», en la que hay que descubrir quién regala entradas y cuánto dinero ha perdido el cine.
- Un panel con las tablas y sus columnas. Si pinchas en una columna, se escribe en la consulta.
- Una pista y la solución en cada ejercicio, y el progreso guardado en el navegador.

## Tablas

`peliculas`, `salas`, `sesiones`, `entradas`, `socios`, `ventas_bar`, `resenas`, `empleados` e `incidencias`. Todos los datos son ficticios.

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `cine-paraiso-sql`) y márcalo como público.
2. Sube `index.html` y este `README.md` con «Add file → Upload files».
3. Entra en **Settings → Pages**. En «Build and deployment» elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
4. En uno o dos minutos estará en `https://TU-USUARIO.github.io/cine-paraiso-sql/`.
